**Analogizer support.** Namco Classic Collection Vol. 1 and Vol. 2 now work
with RndMnkIII's [Analogizer](https://github.com/RndMnkIII/Analogizer)
adapter: the board's own picture on a CRT, and native controllers through
SNAC. Tested on a Pocket with an Analogizer and a CRT. Nothing about the
handheld experience changes with the adapter off.

### What's new since v0.2.1

- **Video out of the adapter's VGA port**: RGBS, RGsB, YPbPr, Y/C (NTSC or
  PAL), or scandoubled for a VGA monitor (plain, 25/50/75% scanlines, HQ2x).
  The signal is the board's: 288x224 at 15.46 kHz, 59.92 Hz.
- **Set up from the core's own menu**, like RndMnkIII's own cores:
  **Analogizer** (Off, On, or "On, Pocket off" to send the picture to the CRT
  only), **Analogizer Video**, **SNAC Adapter** and **SNAC Assignment**. Off
  by default.
- **No `analogizer.bin` file any more.** The v0.3.0-alpha.1 test build read
  its settings from that shared file; this release ignores it, so a copy
  left on your card does no harm.
- **Analogizer H Position / V Position** move the picture on the CRT (16
  pixels left or right; 24 lines up but only 2 down, because the board
  starts its vertical sync just after the picture). They move the sync, not
  the picture, so nothing is cropped.
- **SNAC controllers**: DB15, NES, SNES, PC Engine (2- and 6-button,
  multitap), PlayStation (digital and analog), for players 1 and 2. The
  adapter reports the Pocket's own layout: A = button 1, B = button 2,
  X = button 3, Select = coin, Start = 1P start, R = 2P start. SNAC has not
  been tried with this core yet.
- Fixes since the alpha: the scandoubler is now given the board's real line
  length (414 dots, not 512), and the "Pocket off" blank crosses into the
  video clock safely.

### Read this before you install it

**With this core the Pocket powers the cartridge slot**, adapter or not.
Take any game cartridge out first.

The ND-1 drove a monitor mounted on its side, and the CRT gets its picture
exactly as the board scans it: nothing rotates it. Stand the CRT on its
side, turned clockwise as you face it (top of the set to the right), as the
cabinet's was. Set the adapter up as its
[How to use it](https://github.com/RndMnkIII/Analogizer/wiki/How-to-use-it%3F)
page says (SNAC switch on A, 5 V into its USB-C port, the audio cable into
the Pocket's headphone socket).

### Installing

Unzip onto the SD card root, overwriting previous files. ROMs are not
included: build `ncv1.rom` and `ncv2.rom` with the included `mra_build.py`
from your own MAME romsets and put them in `Assets/namcocollection/common/`.
