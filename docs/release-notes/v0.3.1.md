**H Size: the game's height on a CRT stood on its side.** Confirmed on a
Pocket with an Analogizer and a CRT.

### What's new since v0.3.0

- **Analogizer H Size** (-20% to +20%) sets the width of the picture on the
  CRT. With the set on its side, as this board's monitor was, that is the
  game's *height*, and many TVs have no size control of their own. The core
  plays each line back a little faster or slower; nothing is cropped. The
  board starts hsync only 18 dots after the picture, so first centre the
  picture with H Position (about -16), then widen it. Where the two
  together would reach the sync, the core trims the picture's edge instead,
  so the set never loses sync. It works in the 15 kHz modes (RGBS, RGsB,
  YPbPr, Y/C); the scandoubler modes are unchanged.
- **Fix:** moving a position slider straight back to 0 in one large step
  could invert the CRT's sync for one frame. It can't now.
- The memory clock's timing moved one step to make room; play was checked
  on a Pocket with it.

### Installing

Unzip onto the SD card root, overwriting previous files. ROMs are not
included: build `ncv1.rom` and `ncv2.rom` with the included `mra_build.py`
from your own MAME romsets and put them in `Assets/namcocollection/common/`.
**With this core the Pocket powers the cartridge slot**: take any game
cartridge out first. Stand the CRT on its side, turned clockwise as you face
it (top of the set to the right).
