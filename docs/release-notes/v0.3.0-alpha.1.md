**A test build, for people who own an Analogizer adapter.** It adds analog
video and SNAC controller support to the core. Nobody working on the core owns
an adapter, a CRT or a SNAC harness, so none of it has been tried — that is
what this build is for. If you just want to play the games, stay on
[v0.2.1](https://github.com/plasticbugs/analogue-pocket-namco-volume-1/releases/tag/v0.2.1);
nothing about the handheld experience is meant to change here.

Built from the `analogizer` branch. The core reports itself as `0.3.0-a1`.

### Read this before you install it

**The cartridge slot is powered for every user of this build**, adapter or
not, because that is where the adapter draws its power. Do not leave a game
cartridge in the slot while running this core. If that is not a trade you want,
stay on v0.2.1.

### What to try

Settings live in `Assets/analogizer/common/analogizer.bin`, shared with every
other Analogizer core on your card. Make it with
[Pupdate 5.6.0+](https://github.com/mattpannella/pupdate/releases) or
[Analogizer Configurator 0.7+](https://github.com/RndMnkIII/AnalogizerConfigurator/releases)
and set **ANALOGIZER ENABLE OPTIONS: ON**. With no file present the adapter
stays off and the cart pins stay in high impedance.

- **Video:** RGBS, RGsB, YPbPr, Y/C NTSC, Y/C PAL, SVGA scandoubler.
- **SNAC:** NES, SNES, DB15, PC Engine (including multitap), PSX DualShock.
  The adapter reports the Pocket's own button layout, so A = button 1,
  B = button 2, X = button 3, Select = coin, Start = 1P, R = 2P start. An NES
  pad has no X or R, so button 3 and 2P start are out of reach on one.
- **Blank the Pocket Screen** darkens the handheld's panel while the analog
  output keeps the picture.

The ND-1 drove a vertically mounted monitor, and the analog output is its raster
exactly as the board scans it: 288x224 at 15.46 kHz, 59.92 Hz. Nothing rotates
it, so a CRT has to be turned on its side as the cabinet's was.

### What would be most useful to hear

1. Does a picture come out at all, and in which of the six modes?
2. Are the colours right — particularly Y/C, which is encoded from RGB here?
3. Does your SNAC pad reach all three buttons, coin and both starts?
4. Did anything about the Pocket's own picture, sound or saves change?

Video and SNAC quirks that are really the adapter's belong to the
[Analogizer project](https://github.com/RndMnkIII/Analogizer). The four
questions above are this core's — please open an issue here for those.

### Installing

Unzip onto the SD card root, overwriting previous files. ROMs are not included:
build `ncv1.rom` and `ncv2.rom` with the included `mra_build.py` from your own
MAME romsets and put them in `Assets/namcocollection/common/`.

`docs/analogizer.md` on the branch has the full detail, including an "If it does
not work" section.
